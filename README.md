# Web Projects

A small collection of personal portfolio and web development assignment pages built with HTML, CSS, and JavaScript.

## Project Contents

- `PORT.HTML` - Personal portfolio page. Its profile image is `WhatsApp Image 2026-10-12 at 09.48.16.jpeg` in the project root.
- `assignment of web/assignment1.html` - Student Portal page demonstrating HTML sections, navigation, tables, lists, and form controls.
- `assignment of web/assignment2.html` - Flexbox Quest interface for practicing layout and responsive CSS. It links to `assignment of web/style.css`, which is not currently included in the project; the page also contains inline styles.
- `assignment of web/sea.js/s.js` - Small JavaScript area calculation and console output example.

## Run Locally

No build tools or package installation are required. Open any `.html` file in a web browser. To view the JavaScript example's output, run it with Node.js from the project root:

```sh
node "assignment of web/sea.js/s.js"
```
